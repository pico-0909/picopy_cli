Picopy

یک فریم‌ورک سبک، قابل حمل و صفر-وابستگی برای ساخت رابط خط فرمان (CLI) با پایتون. با چند خط کد، برنامه‌ای حرفه‌ای، زیبا و تعاملی بسازید.

چرا Picopy؟

ساخت یک رابط خط فرمان زیبا و تعاملی معمولاً نیازمند کتابخانه‌های متعدد و پیکربندی پیچیده است. هر کتابخانه وابستگی‌های خاص خودش را دارد، نسخه‌ی پایتون را محدود می‌کند و کاربر نهایی باید قبل از اجرا، چندین دستور pip install بزند. این چرخه‌ی خسته‌کننده باعث می‌شود که بسیاری از پروژه‌ها به جای تمرکز روی منطق برنامه، وقت خود را صرف پیکربندی محیط کنند.

Picopy این مشکل را از ریشه حل می‌کند. تمام کتابخانه‌های ثالث داخل پوشه‌ی پروژه قرار می‌گیرند تا کاربر نهایی نیازی به نصب چیزی نداشته باشد. یعنی کافیست پوشه‌ی پروژه را کپی کنید و برنامه‌تان همه‌جا کار کند، حتی در سیستم‌هایی که اینترنت ندارند یا دسترسی ادمین محدود است.

برای چه کسانی مناسب است؟

اگر توسعه‌دهنده‌ای هستید که می‌خواهد سریع یک ابزار خط فرمان بسازد، Picopy برای شماست. اگر می‌خواهید برنامه‌ای بسازید که بدون نیاز به نصب وابستگی روی سیستم کاربر اجرا شود، Picopy بهترین انتخاب است. اگر به ظاهر و زیبایی ترمینال اهمیت می‌دهید، تم‌ها و رنگ‌های متنوع Picopy را راضی خواهند کرد.

نصب

برای استفاده از Picopy، کافیست فایل WHL را دریافت کنید و با یک دستور نصبش کنید. تمام وابستگی‌ها به‌صورت خودکار نصب می‌شوند.

دریافت فایل WHL

فایل picopy-1.0.0-py3-none-any.whl را از هر جایی که در اختیارتان قرار گرفته دریافت کنید. این فایل شامل کل کتابخانه و اطلاعات نصب است. می‌توانید آن را از طریق ایمیل، پیام‌رسان، حافظه‌ی جانبی یا هر روش دیگری به دست آورید.

نصب با یک دستور

فایل را در یک پوشه قرار دهید، ترمینال را در همان پوشه باز کنید و دستور زیر را اجرا کنید: 

pip install picopy-1.0.0-py3-none-any.whl

pip به‌صورت خودکار وابستگی‌های Picopy (مثل questionary) را از PyPI دانلود و نصب می‌کند. اگر اینترنت ندارید، می‌توانید وابستگی‌ها را جداگانه نصب کنید.

تأیید نصب

برای اطمینان از نصب موفق، این دستور را در ترمینال بزنید: 

python -c "from picopy import App; print('OK')"

اگر OK دیدید، نصب موفق بوده است.

استفاده در کد

بعد از نصب، در هر فایل پایتون می‌توانید بنویسید: 

from picopy import App

حذف نصب

اگر می‌خواهید Picopy را حذف کنید: 

pip uninstall picopy

ارتقا

برای نصب نسخه‌ی جدید، کافیست فایل WHL جدید را دریافت کنید و همان دستور نصب را با اسم فایل جدید اجرا کنید: 

pip install picopy-1.0.1-py3-none-any.whl

pip نسخه‌ی قدیمی را خودکار جایگزین می‌کند.

نکته
اگر دستور pip کار نکرد، از python -m pip استفاده کنید:

python -m pip install picopy-1.0.0-py3-none-any.whl

شروع سریع

بیایید با یک مثال ساده شروع کنیم. در کمتر از دو دقیقه، اولین برنامه‌ی CLI خود را می‌سازید.

قدم ۱: یک فایل بسازید

یک فایل پایتون به نام main.py بسازید و کد زیر را در آن بنویسید: 

from picopy import App

app = App("MyTool")

@app.menu("Main")
def main(m):
    m.go("Say Hi", say_hi)
    m.quit()

def say_hi():
    app.print("Hello!")
    app.pause()

if __name__ == "__main__":
    app.run()

قدم ۲: اجرا کنید

python main.py

یک منو نمایش داده می‌شود با دو گزینه:

  • Say Hi — پیام Hello! را چاپ می‌کند
  • Exit — از برنامه خارج می‌شود

با کلیدهای جهت‌دار (بالا/پایین) حرکت کنید و با Enter انتخاب کنید. با ESC هم می‌توانید خارج شوید.

قدم ۳: شخصی‌سازی

حالا بیایید کمی شخصی‌سازی کنیم. رنگ، آیکون و عنوان را عوض کنید: 

from picopy import App

app = App("MyTool", version="1.0.0", theme="dracula")

@app.menu("Main", title="منوی اصلی", icon="H", color="cyan")
def main(m):
    m.go("Settings", "settings", icon="S", color="yellow")
    m.go("About", "about", icon="i", color="green")
    m.line()
    m.quit("Exit")

@app.form("Settings", icon="S", color="yellow")
def settings(p):
    p.text("Username", default="admin")
    p.yes_no("Dark mode?", default=True)

    @p.save
    def save(v):
        app.ok(f"Saved: {v['username']}")
        app.pause()

@app.form("About", icon="i", color="green")
def about(p):
    p.info("MyTool v1.0.0")
    p.info("A tiny CLI framework.")

if __name__ == "__main__":
    app.run()

حالا برنامه‌ای دارید با منوی اصلی، صفحه‌ی تنظیمات و صفحه‌ی درباره. کاربر با انتخاب هر گزینه به صفحه‌ی مربوطه می‌رود و با Back یا ESC برمی‌گردد.

چرخه‌ی کار

Picopy بر اساس یک چرخه‌ی ساده کار می‌کند. در هر لحظه، یکی از دو حالت فعال است: منو یا فرم. با هر انتخاب، حالت عوض می‌شود. این چرخه تا زمانی که کاربر خارج شود ادامه دارد.

  1. برنامه اجرا می‌شود، منوی اول نمایش داده می‌شود
  2. کاربر یک گزینه را انتخاب می‌کند
  3. اگر گزینه go باشد، به صفحه‌ی مقصد می‌رود
  4. اگر گزینه do باشد، یک تابع اجرا می‌شود
  5. در فرم، فیلدها یکی‌یکی پرسیده می‌شوند
  6. در انتها کاربر ذخیره یا لغو می‌کند
  7. به منوی قبلی برمی‌گردد و چرخه ادامه می‌یابد

شما اولین برنامه‌ی Picopy خود را ساختید. حالا می‌توانید مفاهیم پیشرفته‌تر را یاد بگیرید.

مفاهیم اصلی

Picopy بر پایه‌ی سه مفهوم اساسی ساخته شده است. درک این سه مفهوم، کلید استفاده از کتابخانه است.

App — مدیر کل برنامه

App قلب برنامه‌ی شماست. این کلاس مسئولیت‌های زیر را بر عهده دارد:

  • نگهداری تنظیمات (عنوان، نسخه، تم، عرض)
  • ثبت منوها و فرم‌ها با دکوراتور
  • مدیریت ناوبری بین صفحات
  • نگهداری تاریخچه
  • چاپ پیام‌ها (موفقیت، خطا، هشدار، اطلاع)
  • نمایش Spinner و Progress

برای ساخت یک App:

app = App("MyTool", version="1.0.0", theme="dark")

Menu — منو با دکمه‌ها

Menu یک صفحه‌ی تعاملی است که چند دکمه نمایش می‌دهد. کاربر با کلیدهای جهت‌دار در آن حرکت می‌کند و با Enter انتخاب می‌کند. هر دکمه یا به یک صفحه‌ی دیگر می‌رود (go) یا یک تابع را اجرا می‌کند (do).

Form — صفحه‌ی ورودی

Form یک صفحه‌ی فرم‌محور است. چند فیلد دارد که به ترتیب از کاربر پرسیده می‌شوند. در انتها کاربر می‌تواند ذخیره یا لغو کند.

نحوه‌ی تعامل

App

مدیر کل. تنظیمات، ناوبری، چاپ، و Spinner.

Menu

منو با دکمه‌ها. کاربر انتخاب می‌کند.

Form

فرم با فیلدها. کاربر پر می‌کند.

چرخه‌ی اجرا

  1. صفحه‌ی فعلی پاک می‌شود (با دستور cls)
  2. بر اساس متغیر کنترلی، منو یا فرم رسم می‌شود
  3. ورودی کاربر گرفته می‌شود
  4. بر اساس انتخاب، صفحه‌ی بعدی مشخص می‌شود
  5. به ابتدای حلقه برمی‌گردد

منوها

منو یکی از پرکاربردترین اجزای Picopy است. با منو می‌توانید گزینه‌های مختلف را به کاربر نمایش دهید.

ساختار پایه

@app.menu(name, title=None, icon="", color=None)
def menu_name(m):
    # دکمه‌ها اینجا
    pass

متدهای منو

متد توضیح مثال
m.go() رفتن به صفحه یا منوی دیگر m.go("Settings", "settings")
m.do() اجرای یک تابع m.do("Run", my_fn)
m.line() خط جداکننده m.line()
m.back() دکمه‌ی برگشت m.back()
m.quit() دکمه‌ی خروج m.quit("Exit")

    m.line()
    m.quit("Exit")

منوهای تودرتو

@app.menu("Main")
def main(m):
    m.go("Tools", "tools")
    m.quit()

@app.menu("Tools", icon="T")
def tools(m):
    m.do("Format", format_file)
    m.do("Validate", validate_file)
    m.line()

مثال ۱: Task Manager

from picopy import Appimport json
from pathlib import Path

app = App("Tasks", theme="dracula")
DB = Path("tasks.json")

def load_tasks():
    return json.loads(DB.read_text()) if DB.exists() else []

def save_tasks(tasks):
    DB.write_text(json.dumps(tasks, indent=2))

@app.menu("Main", icon="T")

def list_tasks():
    tasks = load_tasks()
    if not tasks:
        app.warn("No tasks yet!")
    else:
        for i, t in enumerate(tasks, 1):
            app.print(f"  {i}. {t['text']}")
    app.pause()

def add(p):

    p.choose("Priority", ["Low", "Medium", "High"])

    @p.save
    def save(v):

        tasks.append({"text": v["task"]})

        app.ok(f"Task added!")
