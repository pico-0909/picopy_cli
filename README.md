### About

**picopy_cli** is a lightweight Python framework for building interactive command-line interfaces (CLI). With just a few lines of code, you can create professional menus, forms, and interactive pages in the terminal.

All third-party dependencies are vendored inside the project folder, so end users don't need to install anything. Just copy the project folder and it works everywhere — even on systems without internet access.

### Features

- **Lightweight** — No heavy dependencies, instant startup
- **Portable** — Everything in a single folder
- **Zero-Dependency** — End users don't need pip or internet
- **6 Built-in Themes** — dark, light, dracula, nord, gruvbox, mono
- **Rich Widgets** — text, password, confirm, select, multiselect, number, path, info
- **Smart Navigation** — History tracking and automatic back
- **Spinner & Progress Bar** — For long-running operations
- **Rich Colors** — 35+ named colors, 256-color support, and HEX
- **Markup Support** — Inline color tags like `[red]...[/red]`
